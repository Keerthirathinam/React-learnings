JavaScript

Execution context

The environment a piece of JS runs in: variables, scope chain, and this. Created for global, each function call, and each module.

MDN overview javascript.info

Call stack

LIFO stack of function frames. Call pushes, return pops. Async work leaves the stack and comes back later via the event loop.

MDN Call stack

Closures

A function that remembers the variables from the place it was created, even after that outer function returned.

MDN Closures javascript.info

Hoisting

Declarations are registered before the body runs. var becomes undefined; let/const stay in the TDZ; function declarations are fully available.

MDN Hoisting

Scope

Where a name is visible. JS is lexically scoped: look at where the function is written, then walk outward.

MDN Scope Lexical environment

this

For regular functions, this is decided by the call site (method, bare, new, bind). Arrows inherit this from the enclosing scope.

MDN this

Promises

An object for a future value: pending → fulfilled or rejected. Chain with then/catch; always handle rejection.

MDN Promise javascript.info

async / await

Syntax over promises. async returns a promise; await pauses that function and unwraps or throws. Use try/catch and Promise.all for parallel work.

MDN async

Event loop

Run the stack, drain microtasks, then one macrotask, then maybe render. That is why Promise.then beats setTimeout(0).

MDN Event loop javascript.info

Map / Set

Map: any-key dictionary with insertion order. Set: unique values. Prefer over objects when keys are not strings.

MDN Map MDN Set

Prototype & OOP basics

Objects delegate missing properties up [[Prototype]]. Shared methods live on Fn.prototype. Classes are sugar over this chain.

MDN prototype chain

Classes

Constructor + prototype methods + extends/super. Not hoisted like functions. Prefer composition when the tree gets deep.

MDN Classes

Modules (ESM vs CJS)

ESM is static, tree-shakeable, live bindings. CJS is sync require with a snapshot of exports. Browsers need type="module".

MDN Modules Node ESM

Deep vs shallow copy

Shallow copies one level; nested refs are shared. Deep clones the graph. Use structuredClone; JSON drops functions and dates.

structuredClone

Currying

Turn f(a,b,c) into f(a)(b)(c) so you can pre-fill arguments and reuse the rest.

javascript.info

Memoization

Cache results of a pure function by arguments. Worth it only when work is expensive and inputs repeat.

React useMemo

var / let / const

const by default, let if you reassign, never var. var is function-scoped and hoisted to undefined.

MDN let

Regular vs arrow

Regular functions get their own this and can be constructors. Arrows are lexical this, no arguments, not constructable.

MDN arrows

call / apply / bind

call and apply invoke now (list vs array of args). bind returns a new function with locked this.

MDN bind

IIFE

A function you define and run immediately to get a private scope. Modules replaced most of this.

MDN IIFE

Callbacks

A function you pass to be called later. Nesting them is messy; promises flatten the same idea.

MDN callback

Microtasks vs macrotasks

Microtasks (promises) run before the next timer/UI task. Starving the microtask queue blocks paint.

MDN microtasks

Promise.all / race / allSettled

all fails fast; allSettled waits for every result; race takes the first settle (timeouts). Check ok on fetch yourself.

MDN all allSettled

Destructuring, spread/rest, ?., ??, map/filter/reduce

Unpack and copy without mutate. ?. stops on nullish. ?? only replaces null/undefined. map/filter/reduce are the core list tools.

Optional chaining Nullish

Object.freeze

Shallow lock: no add/remove/reassign of own keys. Nested objects can still change.

MDN freeze

Debounce, throttle, deepClone, flatten

Debounce: fire after silence. Throttle: fire at most once per window. Clone with structuredClone. Flatten with flat(Infinity) or recurse.

Array.flat

Event bubbling & listeners

Capture down, bubble up. addEventListener options: capture, once, passive, signal. Remove or abort on teardown.

MDN bubbling

Higher-order function

Takes or returns a function. map, debounce, and React HOCs are HOFs.

First-class functions

Browser APIs: storage, setTimeout, window

localStorage lasts; sessionStorage is per tab; both are strings and XSS-visible. setTimeout is a macrotask. window is the browser global.

localStorage setTimeout

Security: XSS, CSRF, SOP, CSP, encrypt vs hash

XSS runs attacker JS. CSRF rides your cookies. SOP blocks cross-origin reads. CSP allowlists scripts. Encryption is reversible; hashing is not.

OWASP XSS OWASP CSRF MDN CSP

Garbage collection & memory leaks

GC frees unreachable objects. Leaks are leftover listeners, timers, caches, and closures that still point at big data.

MDN memory

WeakMap / WeakSet

Object keys/values held weakly so GC can drop them. Not iterable. Use for caches and private metadata.

MDN WeakMap

Symbols

Unique keys that will not collide. Also power well-known hooks like Symbol.iterator.

MDN Symbol

Iterators & generators

Iterator: next() → {value, done}. Generator: function* that yields and pauses. for…of uses [Symbol.iterator].

MDN iterators

Event delegation

One listener on a parent; inspect event.target. Works for items added later.

javascript.info

AbortController

Pass signal to fetch/listeners; abort() cancels them. Use on unmount and on stale search.

MDN AbortController

Fetch lifecycle

Request → CORS → network → headers → body. Promise rejects on network fail, not on 404. Always check response.ok, then parse once.

MDN Fetch

Regex

Patterns for test/match/replace. Know flags and that a global regex keeps lastIndex.

MDN regex

React

Virtual DOM

A JS description of the UI. React diffs it and patches the real DOM. Predictable updates, not magic speed.

react.dev state/trees

Basic components

Functions that take props and return UI. Keep render pure; side effects go in effects or event handlers.

Your first component

Fiber

React’s unit of work. Lets render pause, resume, and abort — the base of concurrent features.

Fiber architecture notes

Reconciliation & keys

Compare type + key. Keys identify siblings across renders. Index keys break when the list reorders.

Why keys

Hooks & custom hooks

Top-level only, same order every render. Custom hooks reuse stateful logic, not JSX.

Hooks API Custom hooks

Context API

Pass data through the tree without props. Consumers re-render when the value identity changes.

Context

React.memo / useMemo / useCallback

Skip work when inputs are the same. memo = component, useMemo = value, useCallback = function identity.

memo useCallback

Portals

Render into a DOM node outside the parent (modals). React events still bubble through React.

createPortal

Error boundaries

Catch render errors in a subtree and show fallback. Not for event handlers or async.

Error boundaries

Suspense & lazy loading

lazy() splits a component; Suspense shows fallback while it loads (and while some data waits).

lazy Suspense

Navigation

URL → component tree. Use Link for client routing; keep shareable state in the URL.

React Router

useState object/array updates

Replace state, do not mutate. Spread copies; use the functional updater when next depends on prev.

useState

useEffect deps, cleanup, closures

After paint. List every value you read. Cleanup cancels timers/fetches. Missing deps = stale closure.

useEffect

useRef

Mutable box that survives renders without re-rendering. DOM nodes, ids, latest values.

useRef

useContext / useReducer

useContext reads a provider. useReducer is setState for many transitions: (state, action) → next.

useContext useReducer

Component patterns

Controlled = React owns value. Compose with children. Render props/HOCs share logic (hooks preferred). Lift state up. Compound components share implicit context.

Lifting state

Pagination, lifecycle, concurrent, batching

Page in the URL. Render is pure; commit then effects. Concurrent work can be discarded. React 18 batches setState almost everywhere.

Batching React 18 batching

Stale closures & useEffect races

Old render’s function still sees old state. Late fetch overwrites new data. Fix with deps, functional updates, abort.

Fetching in effects

forwardRef / useImperativeHandle

Let a parent hold a child ref. Imperative handle exposes a small API (focus) instead of the whole node.

TypeScript

Interface vs type

Interfaces merge and describe objects. Types can be unions, tuples, mapped types. Both work for props.

TS handbook

Generics

Type parameters so a function/component stays typed for whatever the caller passes. Constrain with extends.

Generics

Union / intersection

A | B is one of them (narrow it). A & B is both. Prefer discriminated unions for state machines.

Unions

Utility types

Partial, Pick, Omit, Record reshape existing types instead of rewriting them.

Utility types

Enums vs const assertion

Prefer as const objects + a value union. Numeric enums have odd runtime reverse maps.

Enums

Typing React props and events

Type props as an object. Events: React.ChangeEvent<HTMLInputElement>. Or ComponentProps<"button">.

React+TS cheatsheet

Redux Toolkit

createSlice, reducers, actions

One call writes reducers and action creators. Inside those reducers you “mutate” a draft; Immer makes it immutable.

createSlice

configureStore

Wires reducers, thunk, DevTools, and good defaults. Add RTK Query middleware here.

configureStore

useSelector / useDispatch

Select a small slice or you re-render too much. Dispatch typed actions. Memoize derived data.

React-Redux hooks

Immer — when not to

Do not mutate and also return a new object. Do not treat class instances as drafts. Outside a produce/reducer, mutate nothing.

Immer in RTK

createApi & endpoints

Queries, mutations, variables, fragments
